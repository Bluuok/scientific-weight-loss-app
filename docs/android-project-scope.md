# 本项目只做安卓手机端

主要使用者为适合减重的高血压合并肥胖老年人，现优先男性。产品保持中文、大字体、少步骤，以“我的计划”为主入口；不开发网页、桌面端或 iOS 产品。

## 交付与自动检查

- 家人使用的 APK 可通过 QQ 等渠道传送后安装，不依赖 Google Play。部分手机需要本人授权外部来源安装。
- 默认 GitHub Actions 运行静态分析、完整 Flutter 测试和安卓 develop 调试 APK 构建。先清理托管 Linux 机器不需要的工具链，缓解磁盘不足；不清理安卓 SDK 和 Java。
- 安卓模拟器集成测试保留为手动选项：运行 Android checks 时勾选 `run_device_tests`。默认 PR 检查不代表已完成模拟器或真机测试。
- CI 使用无效占位配置，不调用真实 AI，不自动发布商店。CI 下载的调试 APK 是构建证据，不等于已接入家庭自用服务的发行包。
- 真机安装、真实 API 测试和家庭配置均需另行验证。密钥不提交到仓库，临床效果也不因测试通过而得到证明。

## 保留边界

上游 iOS 工程与历史说明暂时保留，避免无关的大规模删除；默认流水线不调用 iOS、TestFlight 或商店部署任务。这不等于已经逐文件删除所有跨平台代码。未来 PR 按本文件和根 AGENTS.md 的个人分支范围执行。
