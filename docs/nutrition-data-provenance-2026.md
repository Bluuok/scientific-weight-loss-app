# 食物成分数据来源与可用性门禁（2026-10-19）

## 本轮上线边界

1. 保留当前 **26 个 USDA 食材与 28 个家常食谱**及现有热量、蛋白、脂肪、碳水、膳食纤维和钠的核算。所有基础食材必须有精确 FDC ID、原始状态和 HTTPS 官方溯源；配料引用失效或任何营养数据不完整则启动前拒绝本地餐单库，而非按 0 计算。
2. `NutritionSourceAudit.coverage` 明确公开哪些指标有数据。钾、钙、镁、磷、饱和脂肪 **缺测时保持未知**；不能将现有菜谱称为已满足这些营养指标或适合已知肾病患者。
3. **中国食物成分数据尚未获确认的机器分发授权，所以不下载、不爬取、不在仓库复制官方查询网站数据**。官网可用于人工查证食物身份与原料匹配，但该用途与批量复用许可不同。
4. 对中国本地食物成分表今后的接入前提：确认授权与来源版本；建立 `source_id`/食物编码与可食部、原料生熟、每 100 克单位、检测值/缺测/估计值差异；核验食品状态是否一致；保持不同来源数据不相互覆盖且通过样例交叉检查。未授权不可进入内置 assets。

## 权威来源

- 中国疾病预防控制中心营养与健康所、中国营养学会食物营养成分查询平台：https://nlc.chinanutri.cn/fq/
- 中国公共卫生科学数据中心“中国食物成分数据库”元数据：https://www.phsciencedata.cn/Share/ky_sjml.jsp?id=577e0301-ab65-432a-9bb7-a8342302e589
- 中国疾控《食物成分数据表达规范》解读（缺测和零值必须区分）：https://www.chinacdc.cn/jkyj/yyyjk2/jswj13949/201707/t20170721_296904.html
- USDA FoodData Central 官网及 CC0 授权：https://fdc.nal.usda.gov/api-guide

## 不声称

- 不认为 USDA 的“钙凝固硬豆腐”直接代表中国超市全部豆腐类型。
- 不把食谱份量的食品成分估计视为体检结果。
- 不推荐肾病患者自行执行高钾 DASH 或高蛋白饮食：相关风险由单独安全筛查负责。
