# 家庭周采购清单 / 菜价录入（2026-10-19）

这是一份**基于 7 天计划的采购估算**。系统把 21 餐的原料克数按 `portion` 合计，食盐与烹调油也包含在内，但未计算打卡后实际替换的食物。

- 只接受使用者主动输入的**当地人民币 / 500 克（市斤）**价格；不调用菜价爬虫，不让模型虚构菜价。地区/季节差异由用户改价体现。
- 默认无价格；只有所有计划食材均有有效本地价格时显示完整周估算。价格不全只给已录入部分小计，并突出未标价数量。无法凭小计判断整周预算。
- 克数统一为食材目录可食部的生重或干重。购物需要购买重量（带皮、骨、壳、包装）及食材运输、损耗和烹调缩水，此模型目前**无法可靠估算**，显示提示。
- 采购清单只做参考，不自动压低营养目标，也不会为了价格忽略食材忌口、蛋白和钠。
- 储存在已存在的本地加密 Hive plannerBox；删除或更改一项价格后应重新计算，不调用 AI。价格不随计划复制到别的家庭成员。
- 实证背景：2022 中国心脏健康膳食干预中食材成本约 24 vs 21 元/天，2024 四川菜系子研究约 27.87 vs 25.18 元/天，不能当作本用户家附近的实时菜价。
